# Confluence Frontend

Confluence — From Community Challenges to Real Solutions.

A collaborative civic-tech platform connecting citizens, municipal authorities, universities, and student innovators to identify civic challenges, incubate research-backed solutions, and drive real-world civic impact.

## Features

- **Multi-Role Portals**:
  - **Citizen Portal**: Report civic issues with geo-tagging, track progress, and upvote community concerns.
  - **Municipal / Officer Dashboard**: Review reported problems, triage, assign priority, track adoptions, and manage projects.
  - **University Innovation Hub**: Explore and adopt civic problem statements, launch open calls, and mentor student research batches.
  - **Student Innovator Workspace**: Submit solution pitches, form teams, build MVPs, and track evaluation milestones.
  - **Super Admin Panel**: Manage organizations, user roles, system logs, and platform configurations.

- **Real-time & Interactive UI**:
  - Interactive Leaflet maps for geographic problem visualization.
  - Live statistics, engagement analytics, and status progression tracking.
  - Multi-step proposal and pitch submission wizards.
  - Role switcher for instant cross-persona demonstration.

## Tech Stack

- **React 19**
- **Vite**
- **Lucide Icons**
- **Leaflet & React-Leaflet**
- **Canvas Confetti**

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/DiscoveringRohit/Confluence-frontend-.git

# Navigate to project directory
cd Confluence-frontend-

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
